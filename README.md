# MVC Proje Kampı

MVC (Model-View-Controller) mimarisini öğrenmek ve uygulamak için geliştirilmiş eğitim projesi.

## 📋 Açıklama

Bu proje, MVC tasarım deseni kullanılarak geliştirilmiştir. Web uygulamalarında modern mimari yapıyı anlamak ve uygulamak için kapsamlı bir örnek sunar.

## 🛠️ Teknolojiler

- **JavaScript**
- **HTML5**
- **CSS3**
- **MVC Architecture**
- **AdminLTE Template**

## 🚀 Başlangıç

```bash
# Repository'yi klonlayın
git clone https://github.com/YunusEdizer/mvcprojekampi.git

# Proje klasörüne gidin
cd mvcprojekampi
```

## 🎯 Özellikler

- Klasik MVC mimarisi
- Model katmanı veri yönetimi
- View katmanı UI tasarımı
- Controller katmanı iş mantığı
- Responsive tasarım
- AdminLTE dashboard template
- Bootstrap 4 framework

## 📚 Öğrenme Kaynakları

Bu proje şunları öğretmeyi amaçlar:
- MVC mimarisinin temel kavramları
- Kaygıların ayrılması (Separation of Concerns)
- Temiz kod yazma pratiği
- Frontend best practices
